# 1. MVP 구현 범위 

*- 제출한 예선 MVP 산출물에서 구현한 기능 범위 작성
- 미구현 또는 향후 구현 예정 기능은 제외*

---

Peerfolio MVP는 회원이 자신의 경제정보와 투자자산을 직접 입력한 뒤, 경제적 여건이 유사한 Peer Group의 집계 평균과 자신의 상태를 비교하고 AI 분석 결과 및 임의 Peer 비교를 확인하는 웹서비스이다.

MVP 구현 범위는 다음과 같다.

- 이메일 인증코드 발급, 회원가입, 로그인, 로그아웃, 회원탈퇴
- 나이·월수입·고정지출·월 저축목표·총자산·총부채 입력 및 저장
- 국내주식·해외주식·예적금 및 채권·대체고위험자산 입력 및 저장
- 저장된 금융정보 조회·수정과 요약 카드 표시
- 사용자와 Peer Group 집계 평균의 경제적 여건·투자자산 비교
- 0~100점 위험점수, LOW·MEDIUM·HIGH 단계, 요약 및 AI 분석문구 표시
- Peer Group에서 임의로 제공되는 3명의 익명 프로필 확인
- 선택한 Peer와 막대·원형·레이더 차트 비교
- 현재 AI 분석 결과를 문맥으로 전달하여 어려운 금융·경제 용어와 분석 근거를 질문하는 챗봇

# 3. 사용자 이용 흐름 

*- 사용자가 배포 URL 접속 후 주요 기능을 사용하는 순서 작성*

---

1. 사용자가 배포 URL에 접속해 회원가입 또는 로그인을 한다.
2. 처음 이용하는 경우 정보 입력 화면에서 경제정보와 네 가지 투자자산 금액을 입력해 저장한다.
3. 메인 화면에서 저장한 금융정보 요약을 확인한다.
4. ‘다시 분석하기’를 실행하거나 저장된 최신 분석을 불러온다.
5. 사용자와 Peer Group의 경제정보·투자자산 금액 및 비중 비교 차트를 확인한다.
6. AI가 생성한 위험점수, 위험단계, 요약과 분석문구를 확인한다.
7. 분석 결과에서 이해하기 어려운 용어나 결과가 있으면 챗봇을 연다.
8. 챗봇이 현재 분석 결과를 문맥으로 불러오면 용어와 위험점수의 근거를 질문한다.
9. 화면 하단의 임의 Peer 3명 중 한 명을 선택한다.
10. 비교 모달에서 막대·원형·레이더 차트를 전환하며 사용자와 선택한 Peer를 비교한다.
11. 필요한 경우 정보 입력 화면에서 금융정보를 수정하고 다시 분석한다. 새 분석에서는 새로운 챗봇 세션을 시작한다.
12. 이용을 마치면 로그아웃한다. 로그아웃 또는 세션 종료 후에는 이전 채팅을 불러올 수 없다.

# 4. AI 및 데이터 처리 방식

*- AI가 수행하는 역할 작성
- 사용 데이터와 입력·출력 데이터 작성
- (필요시) 개인정보 또는 민감정보 처리 여부 작성*

---

### 4.1 AI의 역할

AI는 사용자의 금융정보와 개별 Peer가 아닌 Peer Group 집계 평균을 비교하여 다음 결과를 생성한다.

- 사용자와 Peer Group 사이에서 차이가 큰 경제·투자 항목 설명
- 수입·지출·저축 균형, 보유자산 대비 부채, 투자자산 편중 등 위험요인 해석
- 0~100점의 종합 위험점수와 LOW·MEDIUM·HIGH 위험단계 생성
- 위험요약과 최대 5문장의 자연어 분석문구 생성
- 월수입·고정지출·저축목표·보유자산·부채 등 경제적 여건으로 후보의 유사도를 산출한다.
- 투자자산 구성은 비교하려는 핵심 행동이므로 Peer Matching의 주요 기준과 분리한다.
- 최종 Peer Group의 표본 수와 집계 시점은 분석 결과에 포함한다.

### 4.2 입력·출력 데이터

| 구분 | 데이터 |
| --- | --- |
| 사용자 입력 | 나이, 월수입, 고정지출, 월 저축목표, 총자산, 총부채, 국내주식, 해외주식, 예적금·채권, 대체·고위험자산 금액 |
| Peer 비교 입력 | Peer Group 표본 수, 평균 월수입·총자산, 네 자산군의 평균금액·평균비중 |
| AI 출력 | 분석 결과 ID, 종합 위험점수, 위험단계, 위험요약, 분석문구, 생성시각, 제공 가능한 세부 위험점수 |
| 임의 Peer 데이터 | 닉네임, 유사도, 경제정보 요약, 네 자산군 금액·비중. 1:1 차트에만 사용하며 AI 분석 입력에서는 제외 |
| 챗봇 입력 | 현재 분석 결과 ID, 위험점수·단계·요약·분석문구, 질문에 필요한 Peer Group 집계값, 현재 세션의 대화내용 |
| 챗봇 출력 | 금융·경제 용어 설명, 현재 분석 근거의 쉬운 재설명, 일반적인 위험관리 원칙, 투자 권유가 아니라는 안내 |

### 4.3 핵심 분석 기준

| 항목 | 처리 기준 |
| --- | --- |
| 자산 비중 차이 | 사용자 비중 − Peer Group 평균 비중 |
| 0~5%p | 비슷한 수준 |
| 5%p 초과~15%p | 다소 높음·낮음 |
| 15%p 초과~30%p | 높음·낮음 |
| 30%p 초과 | 매우 높음·낮음 |
| 단일 자산군 50% 초과 | 집중 가능성 |
| 단일 자산군 70% 초과 | 높은 집중 위험 |
| 전체 투자자산 0원 | 모든 투자자산 비중과 투자자산 집중 위험을 0으로 처리 |

차이의 크기는 절댓값으로 판정하고 높음·낮음의 방향은 원래 차이의 부호로 결정한다. Peer 평균과 다르다는 사실만으로 위험하다고 판단하지 않고 자산 유형과 집중도를 함께 고려한다. 위험점수와 단계는 LOW 0~33점, MEDIUM 34~66점, HIGH 67~100점으로 일치시킨다.

### 4.4 분석 결과 기반 챗봇 처리

- AI 분석이 완료된 경우에만 챗봇을 사용할 수 있다.
- 챗봇은 현재 분석 결과를 이해하기 위한 후속 설명 기능이며, 별도의 투자상담이나 포트폴리오 추천 기능으로 사용하지 않는다.
- “방어적 자산이 무엇인가요?”, “왜 제 위험단계가 MEDIUM인가요?”와 같이 분석에 등장한 용어나 판단 근거를 질문할 수 있다.
- 특정 종목·상품의 추천, 매수·매도 지시, 가격·수익률 예측 요청에는 답변하지 않고 관련 위험과 일반 원칙을 설명한다.
- 개별 Peer 정보는 챗봇 입력에 포함하지 않으며, Peer Group의 집계값만 필요한 범위에서 사용한다.
- 채팅 메시지는 현재 세션에서만 문맥으로 사용한다. 세션 만료·로그아웃·분석 초기화 시 삭제되며 조회하거나 복구할 수 없다.

### 4.5 개인정보 및 브라우저 저장

- 회원가입과 인증을 위해 이름, 이메일, 비밀번호, 인증코드를 처리한다.
- 사용자가 직접 입력한 나이와 금융정보는 분석을 위해 서버에 저장·조회된다.
- 인증 토큰, 사용자 정보와 최근 분석 결과는 서비스 이용 편의를 위해 브라우저 로컬 스토리지에 저장된다.
- 로그아웃 시 브라우저의 인증정보와 분석 관련 캐시를 삭제한다.
- MVP에서는 합성 Peer 데이터를 사용하며 다른 실사용자의 개별 금융정보를 공개하지 않는다.
- 챗봇 대화내용은 사용자별 채팅 기록으로 영구 저장하지 않으며, 현재 세션 종료 시 삭제한다.

### 5.2 회원 기능 검증

1. 테스트 계정으로 로그인한다.
2. 위 샘플값을 입력하고 저장한다.
3. 메인 화면에 입력값이 요약 카드로 표시되는지 확인한다.

6. 사용자와 Peer Group의 비교 차트 및 임의 Peer 3명이 표시되는지 확인한다.
7. Peer 한 명을 선택해 세 종류의 1:1 비교 차트를 확인한다.
8. 챗봇을 열고 “변동성 노출이 무슨 뜻인가요?”를 질문한다. 현재 분석과 연결된 설명이 제공되는지 확인한다.
9. “왜 제 위험단계가 MEDIUM인가요?”와 같이 후속 질문을 입력하고 현재 세션의 문맥을 이어 답변하는지 확인한다.
10. “어떤 주식을 사야 하나요?”를 질문했을 때 종목 추천을 제한하고 위험요인이나 일반 원칙을 안내하는지 확인한다.
11. 로그아웃하거나 채팅 세션을 종료한 뒤 이전 채팅이 조회·복구되지 않는지 확인한다.
12. 정보 입력 화면에 재진입해 기존값이 표시되고 수정값이 저장되는지 확인한다.
13. 로그아웃 후 메인 화면 접근 시 로그인 화면으로 이동하는지 확인한다.

### 5.3 MVP 제한사항

- 모바일 화면 최적화는 일부 화면에서 제한적이므로 데스크톱 Chrome 환경을 권장한다.
- 챗봇 대화는 현재 세션에만 유지되므로 세션 종료 후 이전 대화를 다시 확인할 수 없다.
